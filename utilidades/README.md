# Utilidades técnicas

Scripts operativos y ejemplos PL/SQL organizados por aplicación.

- [FND](FND/README.md): contexto EBS y unidad operativa, envío de concurrentes y juegos, espera de solicitudes y plantilla de programa concurrente.

[consultas](../README.md) contiene diagnósticos de lectura; [Interface](../Interface/README.md) reúne cargas e integraciones y [Application_Server](../Application_Server/README.md) documenta tareas del servidor.

Revisa los requisitos, parámetros, efectos y control transaccional de cada utilidad antes de ejecutarla. Publicar estos ejemplos no los instala ni ejecuta en una instancia EBS.
